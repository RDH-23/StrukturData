## 📂 Struktur Repositori

Materi telah dikelompokkan ke dalam folder-folder berikut agar lebih teratur:

### 1. Struktur Data Linear
* **Stacks:** Implementasi konsep LIFO.
* **Queues:** Implementasi konsep FIFO.
* **Deques:** Antrean dua ujung.

### 2. Algoritma Searching & Sorting
* **Sorting Dasar:** Bubble Sort, Selection Sort, dan Insertion Sort.
* **Sorting Lanjutan:** Merge Sort, Quick Sort, dan Counting Sort.
* **Searching:** Sequential Search, Binary Search, dan Hashing.

### 3. Konsep Lanjutan & OOP
* **Fungsi Rekursif:** Pemecahan masalah dengan fungsi yang memanggil dirinya sendiri.
* **OOP Dasar:** Pengenalan Class dan Object dalam Python.
* **Linked List:** Implementasi struktur data dinamis.
* **Binary Tree:** Implementasi struktur data pohon biner.

### 4. Evaluasi & Tugas
* **Tugas Praktikum:** Kumpulan tugas mingguan (Tugas 01 & 02).
* **UTS:** Dokumentasi pengerjaan Ujian Tengah Semester.
