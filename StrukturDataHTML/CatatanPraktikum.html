Linear Data Structure: Queues¶

Definisi¶

Queues atau antrian merupakan struktur data dimana penambahan data baru dan penghapusan data berada di ujung yang berbeda. Hal ini berbeda dengan stacks, dimana penambahan data baru dan penghapusan data, dilakukan pada ujung yang sama. Pada Queues, seperti halnya antrian, penambahan data baru dilakukan di suatu ujung atau yang dikenal dengan nama rear, dan penghapusan data dilakukan pada ujung yang dikenal dengan nama front, seperti yang terlihat pada Gambar 1 berikut

Jika konsep penambahan atau penghapusan data pada stacks dikenal dengan nama LIFO (Last In First Out), maka pada Queues menggunakan konsep FIFO (First In First Out).

Operasi¶

Berikut operasi dasar pada Queues:

  1. queue (), inisialisasi struktur data queue kosong
  2. enqueue (data), penambahan data baru pada queue
  3. dequeue (), penghapusan data
  4. isEmpty(), pengecekan apakah queue dalam keadaan kosong

def bubbleSort(data):
  for i in range(len(data)):
    swapped = False
    print("Iterasi ke-",i+1)
    for j in range(1, len(data)-i):
      if data[j-1]>data[j]:
        data[j],data[j-1] = data[j-1],data[j]
        swapped = True
      print("Langkah ke-",j,"=",data)
    print()

    if not swapped:
      break

  return data

Selection Sort¶

Algoritma sorting dengan mencari bilangan terkecil kemudian mengurutkannya.

In [ ]:
def selectionSort(data):
  for i in range(len(data)-1):

    # iterasi untuk mencari nilai minimal
    min_id = i
    for j in range(i+1, len(data)):
      if data[j] < data[min_id]:
        min_id = j

    # melakukan swapping
    data[i], data[min_id] = data[min_id],data[i]

  return data

def insertionSort(data):
  for i in range(1,len(data)):
    print(f"Iterasi ke-{i} : {data}")
    key = data[i]
    ind = i-1
    while ind >= 0 and key < data[ind]:
      data[ind+1] = data[ind]
      ind -= 1
      print("perubahan:",data)
    data[ind+1] = key
    print(data)

  return data

def binarySearch(listData, search):
  first = 0
  last = len(listData) - 1
  found = False

  while first <= last and not found:
    mid = (first + last) // 2

    if listData[mid] == search:
      found = True
    else:
      if listData[mid] > search:
        last = mid - 1
      else:
        first = mid + 1

  return found

class Hash:
  def __init__(self):
    self.panjang = 10
    self.table = self.hashTable()

  def remainderHashFunction(self, data):
    return data % self.panjang

  def hashTable(self):
    return [None for _ in range(self.panjang)]

  def appendTable(self, data):
    for i in range(len(data)):
      idx = self.remainderHashFunction(data[i])
      if self.table[idx] == None:
        self.table[idx] = [data[i]]
      else:
        self.table[idx].append(data[i])

  def search(self, target):
    idx = self.remainderHashFunction(target)
    if self.table[idx] != None:
      for el in self.table[idx]:
        if el == target:
          return True
    return False
